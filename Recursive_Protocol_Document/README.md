# Recursive Protocol Document Workspace

This folder is for drafting the professor-facing document about **Recursive Protocol-Guided Agentic Prototyping**.

## Workflow

1. Create a complete Chinese DOCX draft first.
2. User manually edits the DOCX for high-level direction and selected details.
3. Read the user-edited DOCX and revise the Chinese version.
4. Convert the confirmed Chinese version into English.
5. Polish the English DOCX for academic memo tone and wording.

## Folder Structure

- `drafts/`: generated Chinese and English draft DOCX files.
- `manual-edits/`: user-edited DOCX versions.
- `exports/`: final deliverables.
- `evidence/`: copied or summarized evidence used by the document.
